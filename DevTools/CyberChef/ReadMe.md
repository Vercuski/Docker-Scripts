# CyberChef
GCHQ's "Cyber Swiss Army Knife": build recipes from 400+ operations - encoding (Base64, hex, URL), hashing,
encryption, compression, X.509 / JWT parsing, regex extraction, date and data-format conversion - and run them on
pasted text or files. Everything runs client-side in the browser.<br>
UI: http://localhost:8158<br>

Standalone and stateless (no volumes, no other stack needed). Recipes can be shared as URLs
(`http://localhost:8158/#recipe=...&input=...`) and saved in the browser's local storage.

https://gchq.github.io/CyberChef/
