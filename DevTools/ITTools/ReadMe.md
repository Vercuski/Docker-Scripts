# IT-Tools
A collection of ~80 small developer utilities in one web page: GUID/ULID generators, hash and HMAC, JWT parser,
Base64/URL encoders, cron expression parser, JSON/YAML/TOML/XML converters, regex tester, date-time converter,
chmod and IPv4 subnet calculators, QR codes and more. Everything runs client-side in the browser.<br>
UI: http://localhost:8157<br>

Standalone and stateless (no volumes, no other stack needed). The upstream project tags images by date
(`2024.10.22-7ca5933` is the latest release).

https://github.com/CorentinTh/it-tools
