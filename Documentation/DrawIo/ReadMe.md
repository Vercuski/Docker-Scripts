# draw.io (diagrams.net)
Self-hosted diagram editor. UI: http://localhost:8111/?offline=1<br>
<br>
Stateless: diagrams are opened from and saved to your own disk (or GitHub, OneDrive etc. from the editor),
nothing is stored in the container. `?offline=1` hides the cloud storage options.<br>
Tip: save as `.drawio.svg` or `.drawio.png` to get an image that GitHub renders and draw.io can still edit.

https://github.com/jgraph/docker-drawio
