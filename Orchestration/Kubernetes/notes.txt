NOTE: The Kubernetes Dashboard project has been archived and is no longer maintained.
Headlamp (https://headlamp.dev) is the recommended replacement - see the kubernetes.io blog post
"From Kubernetes Dashboard to Headlamp" (2026-06-01). The steps below still work for an existing Dashboard install.

https://github.com/kubernetes/dashboard/blob/master/docs/user/access-control/creating-sample-user.md

Creating a Service Account + admin binding
  - kubectl apply -f dashboard-adminuser.yaml
  - kubectl apply -f cluster-rolebinding.yaml

Getting a (short-lived) Bearer Token for ServiceAccount
  - kubectl -n kubernetes-dashboard create token admin-user

Getting a long-lived Bearer Token for ServiceAccount
  - kubectl apply -f long-lived-bearer-token.yaml
  - kubectl get secret admin-user -n kubernetes-dashboard -o jsonpath={".data.token"} | base64 -d

Clean up
  - kubectl -n kubernetes-dashboard delete secret admin-user
  - kubectl -n kubernetes-dashboard delete serviceaccount admin-user
  - kubectl delete clusterrolebinding admin-user

Proxy
  - kubectl proxy
  URL: http://localhost:8001/api/v1/namespaces/kubernetes-dashboard/services/https:kubernetes-dashboard:/proxy/
