Getting started

1. CreateNetwork.bat / CreateNetwork.sh — creates GroupNetwork (192.168.16.0/24, gateway 192.168.16.1).
2. CreateVolumes.bat / CreateVolumes.sh — creates the host folders behind the bind mounts (ROOT_VOLUME_DIR=D:).
3. cd <Category>/<Tool> then docker compose up -d

Every settable value (image tag, host port, static IP, credentials) lives in each stack's .env; the compose files use ${VAR:-default}. Passwords are usually only applied the first time a data folder is initialised. docker compose config shows the resolved values.
