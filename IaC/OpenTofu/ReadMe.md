# OpenTofu CLI
The Linux Foundation's open-source (MPL) fork of Terraform. Same HCL and workflow; providers come from
registry.opentofu.org. Extras over Terraform include client-side state encryption.<br>
<br>
`docker exec -it opentofu tofu init` - this folder is mounted at `/infra`, so put `.tf` files here
(or change the mount to your project folder).

https://opentofu.org/docs/
